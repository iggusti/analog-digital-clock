# analog-digital-clock

A simple analog and digital clock web application built with HTML, CSS, and JavaScript. Displays real-time clock with both analog hands and digital readout.

![Clock Preview](https://github.com/iggusti/analog-digital-clock/assets/25238163/451623b1-8d0c-4979-ada9-e0e90c314e6d)

## Features

- Analog clock with rotating hour, minute, and second hands
- Digital clock display (HH:MM:SS)
- Real-time updates every second
- Responsive and centered layout
- Minimalist dark-themed design

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Structure

```
analog-digital-clock/
├── index.html   # HTML structure (analog + digital clock)
├── style.css    # Styling and layout
├── main.js      # Clock logic and real-time updates
└── README.md    # Documentation
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/iggusti/analog-digital-clock.git
```

2. Open `index.html` in your browser:

```bash
# using VS Code Live Server, or simply open the file directly
```

No build step or dependencies required — it runs purely in the browser.
